# Pipeline de Dados com IoT e Streamlit

## 📌 Descrição do Projeto
Este projeto consiste no desenvolvimento de um pipeline de dados completo focado no processamento e análise de leituras de temperatura recolhidas por dispositivos IoT. O fluxo abrange desde a ingestão e tratamento de dados utilizando Python e Pandas até ao armazenamento numa base de dados relacional, culminando na criação de vistas SQL analíticas e na visualização interativa através de um dashboard construído com Streamlit e Plotly.

## 🛠️ Tecnologias Utilizadas
- **Python**: Linguagem principal para o desenvolvimento do script de pipeline e da aplicação web.
- **Pandas**: Biblioteca especializada na manipulação e transformação de dados.
- **SQLAlchemy**: Camada de abstração e gestão de ligação à base de dados.
- **Streamlit**: Framework para a criação e publicação do dashboard analítico web.
- **Plotly**: Biblioteca de visualização gráfica avançada e interativa.
- **Git & GitHub**: Controlo de versão do código-fonte.
